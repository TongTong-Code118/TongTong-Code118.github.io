# Tong Tong's Blog

这是一个使用 Hexo 与 NexT Gemini 主题搭建的个人博客，记录量化研究、学习笔记和生活随笔。

## 本地预览

```bash
npm install
npm run server
```

访问 `http://localhost:4000`。

## 发布文章

文章按主题保存在 `source/_posts/量化研究`、`source/_posts/随笔` 等文件夹中。新增 Markdown 文件并填写标题、日期、分类和标签，推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。
